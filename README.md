## 📌 Sobre el proyecto

Este proyecto consiste en el desarrollo de mi **portafolio web personal**, creado como un espacio para organizar y presentar mi trabajo durante mi formación en Ingeniería en Informática.

El sitio reúne información sobre mis proyectos de desarrollo de software, proyectos académicos, tecnologías utilizadas, formación complementaria y medios de contacto.

Además de funcionar como presentación profesional, el desarrollo del portafolio me ha permitido poner en práctica conocimientos de desarrollo web y mejorar la forma en que documento y presento mis proyectos.

---

## ✨ Características

- 👨‍💻 Presentación de mi perfil.
- 🚀 Sección de proyectos.
- 🎓 Proyectos académicos.
- 🛠️ Tecnologías y herramientas.
- 📜 Cursos, constancias y certificados.
- 📄 Acceso a mi CV.
- 🌙 Modo claro y oscuro.
- 📱 Diseño adaptable a diferentes tamaños de pantalla.
- 📫 Información de contacto.

---

## 🛠️ Tecnologías utilizadas

### HTML5

Utilizado para definir la estructura y contenido de las diferentes secciones del sitio.

### CSS3

Utilizado para el diseño de la interfaz, distribución de elementos, adaptación a diferentes tamaños de pantalla y estilos del modo claro y oscuro.

### JavaScript

Utilizado para agregar interactividad y comportamiento dinámico a diferentes elementos del portafolio.

### Git y GitHub

Utilizados para el control de versiones y almacenamiento del código fuente.

### Vercel

Utilizado para desplegar y mantener disponible públicamente el portafolio.
