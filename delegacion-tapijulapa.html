Objetivo del sitio

Centralizar información útil para la ciudadanía mediante una página web clara, ligera y accesible desde dispositivos móviles y computadoras.

El sitio busca facilitar la consulta de servicios, costos, anuncios y medios de contacto sin depender únicamente de redes sociales o atención presencial.

Desarrollo del proyecto

Este proyecto fue desarrollado durante mi etapa en sexto semestre de CECYTE, como una página web estática para apoyar la difusión de información de la Delegación de Tapijulapa durante el último año de gestión del delegado en turno.

El sitio fue construido utilizando HTML, CSS y JavaScript, cuidando la estructura semántica, la organización visual y la compatibilidad con distintos tamaños de pantalla.

Se diseñaron secciones para mostrar información institucional, servicios disponibles, avisos importantes, convocatorias y datos de contacto, priorizando una navegación simple para usuarios sin conocimientos técnicos.

Actualmente el sitio ya no se encuentra en uso, debido a que fue creado para una administración específica cuyo periodo concluyó. Sin embargo, el proyecto se conserva como evidencia de desarrollo web, diseño responsivo y organización de información pública.
