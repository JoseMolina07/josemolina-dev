Objetivo del sistema

Automatizar procesos administrativos y facilitar el manejo de pacientes, estudios clínicos y reportes dentro de la clínica.

También se buscó construir una solución funcional que pueda ejecutarse localmente sin depender de internet.

Desarrollo del proyecto

El desarrollo del sistema se realizó a lo largo de un semestre académico como parte de distintas materias de la universidad, incluyendo Desarrollo Web, Herramientas para el Diseño de Aplicaciones, Taller de Base de Datos y Desarrollo e Integración de Sistemas de Información.

El proyecto fue construido utilizando una arquitectura separada entre frontend, backend y base de datos. La interfaz fue desarrollada con HTML, CSS y JavaScript, mientras que el servidor utiliza Node.js y Express para manejar la lógica y comunicación con SQLite.

Entre las funcionalidades implementadas se encuentran: autenticación de usuarios, manejo de roles, generación de recibos, control de estudios médicos, historial clínico y reportes administrativos.
