Objetivo del proyecto

Diseñar una sucursal bancaria funcional contemplando distribución física, conectividad, cableado, segmentación de red y organización de equipos.

El proyecto buscó integrar conceptos de redes, infraestructura tecnológica y diseño físico en un entorno empresarial simulado.

Desarrollo del proyecto

Este proyecto fue desarrollado como práctica académica orientada al diseño de infraestructura tecnológica para entornos empresariales.

Se realizó el modelado tridimensional de una sucursal bancaria utilizando SketchUp, contemplando áreas de atención, oficinas, distribución de equipos y espacios de trabajo.

Paralelamente se trabajó en la simulación de red mediante Cisco Packet Tracer, configurando dispositivos de red, direccionamiento IP y estructura de conectividad para representar un entorno funcional.

También se consideraron aspectos de organización física, cableado estructurado, segmentación y distribución de equipos tecnológicos dentro de la sucursal.

Características principales

El proyecto incluye modelado 3D de la sucursal, simulación de red, organización de infraestructura tecnológica y representación visual de un entorno bancario empresarial.

Se trabajó con conceptos relacionados con switches, routers, conectividad, cableado y distribución física de dispositivos para lograr una integración coherente entre infraestructura y red.
