Objetivo del proyecto

Diseñar un robot autónomo capaz de detectar y seguir una línea mediante sensores infrarrojos y lógica de control programada.

El proyecto buscó aplicar conceptos básicos de automatización, sensores y programación orientada al control de movimiento.

Desarrollo del proyecto

Este proyecto corresponde a un fork de un robot siguelíneas basado en Arduino Nano. Mi contribución se centró en corregir el mapeo de pines del puente H y mejorar la estabilidad del control de motores durante el seguimiento de línea.

Durante la revisión del código se identificaron conflictos en la asignación de pines digitales, lo que afectaba la respuesta de los motores. Se ajustó la configuración para que el Arduino Nano trabajara correctamente con el driver TB6612FNG y el módulo de sensores reflectivos QTR-8A.

También se realizaron pruebas de funcionamiento para validar que el robot respondiera de forma estable a las señales de los sensores, eliminando fallos de movimiento y mejorando su consistencia durante el recorrido.

Contribuciones realizadas

Corrección de pines

Corrección de la asignación de pines del puente H para su uso con Arduino Nano.

Ajuste del código

Modificación del código para evitar conflictos entre pines digitales.

Mejora de motores

Mejora en la respuesta de los motores durante el seguimiento de línea.

Componentes y tecnologías utilizadas

Control y sensores

Arduino Nano, C/C++ y módulo QTR-8A de sensores reflectivos.

Control de motores

Driver TB6612FNG, puente H y micro motorreductores tipo Pololu 35mm 3000rpm 10:1.

Estructura física

Cable plano, PCB para seguidor de línea, kit de llantas y piezas impresas en 3D para las llantas y la parte frontal.

Resultado

Después de las correcciones realizadas, el robot respondió de forma estable y consistente a las señales de los sensores, eliminando fallos de movimiento y mejorando su comportamiento durante el seguimiento de línea.
